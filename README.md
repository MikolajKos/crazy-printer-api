# Crazy Printer API 🖨️🔥 (WIP)
_"Because generating 2 Terabytes of fake logs shouldn't be boring."_

High-performance, asynchronous mock log generator written in C++20 using cpp-httplib and nlohmann/json. Capable of saturating NVMe drives while complaining about low magenta ink. Built as a stress-testing tool for distributed systems (like LogGrid).
